# Awesome Design (Premium System Replicator)

## Cuándo activar esta skill
- Al solicitar interfaces con acabados oscuros industriales (estilo Linear).
- Al diseñar gradientes complejos o interfaces fintech hiper-limpias (estilo Stripe).
- Al estructurar layouts hiper-minimalistas orientados a desarrolladores (estilo Vercel).

## Cómo ejecutar la clonación
1. Revisa si en la carpeta raíz del proyecto existe un archivo complementario llamado `DESIGN.md` que contenga los tokens específicos solicitados.
2. Si el usuario pide un estilo específico (ej. "estilo Stripe"), emula sus componentes característicos: bordes sutiles, fondos degradados pastel y tipografías nítidas.
3. Asegura el uso estricto de variables globales CSS o configuraciones de Tailwind que mapeen estos estilos de gama alta.
